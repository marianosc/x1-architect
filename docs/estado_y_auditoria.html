📋 Resumen del proyecto

Qué es: una granja de minería de estrategias de trading en Python + MetaTrader 5. Genera reglas candidatas, las valida contra un juez honesto y busca quedarse solo con las que tienen ventaja real.

Dónde está (junio 2026): el minero v108 está completo y validado. Se construyó por bloques: monkey paralelo (B0), fitness honesto (B1), gramática formulaica (B2), algoritmo genético con warm-start (B3), barrido multi-activo (B4) y acción de precio (B5).

Veredicto, con rigor estadístico: ningún método, activo ni timeframe superó el umbral deflactado (DSR ≥ 0,95). El edge no está en el OHLC (ni indicadores técnicos ni geometría del precio) de estos mercados líquidos. No es un fracaso: es una verdad medida, que casi nadie alcanza.

Lo que quedó construido: un pipeline de validación honesto — motor calibrado a MT5 (−0,009%), monkey paralelo bit-idéntico, validación cruzada (CPCV), algoritmo genético y deflación estadística (DSR) — reutilizable para juzgar cualquier estrategia futura. Historia completa en libro_de_vida.html.

Cómo se retoma: salir del OHLC hacia información que el precio no contiene → features macro del oro (tasas reales, DXY) o pares oro–plata. Ver la sección "Vías para retomar" abajo.

🚀 Vías para retomar (elegí la próxima)

El OHLC se agotó con rigor. Las dos primeras traen información que el precio no contiene (la mayor probabilidad de aportar algo nuevo); las otras dos son técnica/insumo para después.
  • INFO NUEVAFeatures macro del oro El oro se mueve por tasas reales y por el dólar (DXY), no por un RSI. Conseguir/alinear DXY, real yields (FRED), VIX. Es lo que el OHLC del oro no tiene.
